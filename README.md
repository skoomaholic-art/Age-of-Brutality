# Жестокий Век

Репозиторий настольной стратегической игры **«Жестокий Век»**.

## Текущий канонический билд

**V5.7.1-STABLE**

Эта ветка собрана на стабильном шестираундовом ядре V5.7.0. Экспериментальная редакция с порогом победы 30 ОП и незакрытыми `RULE_PENDING` не смешивается с текущим стабильным билдом.

## Репозиторий — источник истины

Все дальнейшие наработки проекта ведутся **только через этот репозиторий**.

Любой обработанный фидбэк сначала вносится в Rules / Data / Cards / Arena / AI / QA и фиксируется коммитом. Только после этого пользователю выдаётся собранный файл или билд для ручной проверки.

Файлы, переданные пользователю в чат, предназначены для того, чтобы «пощупать» продукт руками, и не являются отдельной актуальной веткой проекта.

Полный порядок работы описан в [`docs/WORKFLOW.md`](docs/WORKFLOW.md).

### Базовые принципы синхронизации

Все изменения должны проверяться по цепочке:

`ПРАВИЛА → MASTER GAME DATA → КАРТОЧКИ → ARENA → AI → ПЛЕЙТЕСТ`

Числовые параметры и условия должны совпадать во всех источниках. Если правило не определено, оно не должно молча изобретаться в Arena или AI.

## Структура

- `rules/` — актуальные правила.
- `data/` — Master Game Data и конфигурация AI.
- `cards/` — карточки и шаблоны карточек.
- `arena/` — игровой HTML-билд Arena.
- `map/` — финальная иллюстрированная карта и каноническая сухопутная топология.
- `docs/` — технический аудит, changelog и рабочий процесс.
- `playtest/` — шаблон лога для новых плейтестов.
- `qa/baseline-v5.7.0/` — исторические результаты baseline QA; они не являются свежим regression-тестом V5.7.1.

## Статус V5.7.1-STABLE

- Завершение партии: после 6-го раунда.
- Верхний лимит Влияния в стабильной ветке не установлен.
- Термин дипломатии унифицирован как «Право прохода».
- В Arena предусмотрены отдельные представления «Дипломатия» и «Дома / статистика».
- Используется финальная иллюстрированная карта V5.7.1.

### Что ещё требует проверки

Свежий полный regression QA именно для V5.7.1-STABLE ещё должен быть проведён. Исторические результаты V5.7.0 сохранены отдельно и не переименовываются в результаты V5.7.1.

Также семейные командиры и связанные с ними состояния должны оставаться предметом отдельной сверки Rules ↔ Data ↔ Arena ↔ AI перед признанием механики полностью закрытой.

## Запуск Arena

Откройте файл из `arena/` в современном браузере.

## Правило работы с версиями

Не смешивать в одном релизе стабильную V5.7.x и незавершённые экспериментальные механики без отдельного подтверждённого решения и синхронизации всех зависимых источников.
