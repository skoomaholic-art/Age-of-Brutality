# AI

Текущая AI-логика V5.7.2-PLAYABLE-RC2 пока хранится в Master Game Data и Arena engine patches.

Отдельный полностью нормализованный AI config/source ещё не выделен в самостоятельный канонический файл.

Для RC2 подтверждено ненулевое coverage династических действий, рождений, набегов и prisoner decisions. Числовые AI scoring weights являются implementation-параметрами и должны балансироваться плейтестами, а не трактоваться как правила для людей.
