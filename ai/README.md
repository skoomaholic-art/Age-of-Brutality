# AI — V5.7.2 House Agents

## Статус

В проекте теперь есть самостоятельный нормализованный AI-слой:

- `config/canonical_v5.7.2.json` — канонические AI-параметры, вынесенные из MGD и prisoner module;
- `engine/house_agent.js` — объяснимый scoring engine, который выбирает **только из LEGAL_ACTIONS**;
- `engine/prisoner_agent.js` — решения по плену/выкупу с обязательным reason log;
- `engine/multi_agent_coordinator.js` — координатор шести Домов;
- `tests/house_agents.test.js` — детерминированные smoke/regression tests;
- `../tools/check_ai_config_v5_7_2.js` — проверка рассинхрона AI config ↔ MGD ↔ prisoners.

## Главный принцип

`RULES / ARENA STATE → LEGAL_ACTIONS → AI SCORE → DECISION → EXPLANATION LOG`

AI не создаёт собственные действия и не обходит правила. Если действие невозможно оплатить, запрещено состоянием, дипломатией, картой или иным правилом, оно не должно попадать в `LEGAL_ACTIONS` и агент его не увидит.

## Что уже канонизировано

Из текущего MGD перенесены существующие параметры:

- neutral route base `6`;
- enemy route base `5`;
- возврат домашней территории `+6`;
- возврат столицы `+12`;
- завершение острова `+9`;
- первая половина центра `+4`;
- порт `+3`;
- чужая столица `+10`;
- защищённая цель `-1` за защитника;
- PvP escalation R1→R6: `0 / 1 / 2 / 4 / 6 / 8`;
- late-neutral penalty R1→R6: `0 / 0 / 0 / 1 / 2 / 3`;
- морские ограничения и стратегические планы;
- diplomacy soft-cap: `2`, для Ортайна `3`;
- prisoner AI factors и обязательные поля лога.

## Домовые агенты

Создаются агенты для:

- Варкайр;
- Сайрвен;
- Ортайн;
- Эркай;
- Тасвар;

Сейчас им **не назначены выдуманные personality-веса**. Они различаются реальным игровым состоянием, правилами своего Дома, активной Амбицией/целями, территориальным положением и подтверждёнными исключениями в MGD. Отдельные personality-профили должны появляться только после массовых плейтестов.

## Плен и выкуп

`PrisonerAgent` следует canonical prisoner module:

- случайный размер выкупа не используется;
- учитываются утверждённые факторы;
- `EV-P06 / Съезд заложников` фиксирует выкуп в `2 золота`;
- обязательный лог: `available_options`, `factor_scores`, `offered_N`, `decision`, `reason`.

Числовые веса факторов пленников пока **не утверждены** и поэтому не захардкожены. В canonical module их статус: `IMPLEMENTATION_BALANCE_TEST`.

## Implementation-only решения

Следующее является технической политикой AI, а не правилом для человека:

- детерминированный tie-break нужен для воспроизводимых плейтестов;
- совпадение с уже выбранным strategic plan имеет приоритет при равных условиях;
- diplomacy soft-cap понижает приоритет нового отношения, но не делает легальное действие нелегальным;
- возврат собственной столицы сейчас использует специфический бонус `+12`, а не складывает `+6 +12`. Это защитное решение до восстановления полного старого Arena executable и проверки исторической реализации.
- четвёртый воин в законном Марше остаётся доступен человеку и проходит
  обычную проверку лимита территории; только AI-оценка насыщает вклад
  `force` на трёх воинах, чтобы выбор количества не стал непреднамеренным
  множителем баланса Домов.

## Интеграция с current Arena

AI-слой подключён к `arena/builds/V5.7.2_PLAYABLE_CURRENT_DEV.html` через `arena/source/current/ai_adapter.js` и strategy patch. Current Arena формирует `LEGAL_ACTIONS`, агент выбирает только из них, а решение и score/reason попадают в Journal.

Интеграция проверяется House-agent tests, tabletop/invariant tests и 100/500-seed Game Master regression. Отдельный real-browser smoke остаётся release gate перед продвижением DEV-линии в STABLE.
