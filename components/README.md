# Components

Полный канонический BOM физических компонентов **ещё не утверждён и не мигрирован в GitHub**.

Чтобы физический контур можно было проверять уже сейчас, в
[`draft_bom_v5.7.2.md`](draft_bom_v5.7.2.md) зафиксирована рабочая ведомость:
известные минимальные количества отделены от позиций, которым нужна
утверждённая производственная спецификация. Это не превращает расчёт в
STABLE BOM и не закрывает `COMPONENTS-001`.

Этот каталог зарезервирован для:

- жетонов;
- планшетов Домов;
- player aids;
- счётчиков/маркеров;
- print source;
- утверждённого BOM.

Отсутствие Components/BOM не блокирует цифровой плейтест Arena
V5.7.2-PLAYABLE-CURRENT-DEV, но блокирует STABLE/PnP.
