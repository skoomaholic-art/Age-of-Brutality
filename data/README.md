# Game Data — V5.7.2-DEV

GitHub `main` является единственным source of truth проекта.

Текущая data-структура мигрирует от монолитного snapshot к модульным каноническим данным. Чтобы разные потребители не выбирали приоритеты самостоятельно, граф источников зафиксирован в `canonical_manifest_v5.7.2.json`.

## Канонические источники

- `master_game_data_v5.7.2-dev.json` — DEV snapshot основных таблиц. Часть унаследованных prisoner/ransom-полей в нём пока устарела.
- `prisoners_v5.7.2-dev.json` — **канонический модуль механики плена и выкупа**; имеет приоритет над конфликтующими prisoner/ransom-полями snapshot.
- `canonical_manifest_v5.7.2.json` — машинно-читаемый граф приоритетов и известных нерешённых source-конфликтов.

Регенерация дублируемых полей:

`node tools/reconcile_v5_7_2.js --write`

Проверка:

`node tools/reconcile_v5_7_2.js --check`

## Подтверждённое правило плена

После захвата доступны:

1. Отпустить пленника.
2. Взять в плен.
3. Требовать выкуп N.
4. Казнить.

Выкуп между людьми — переговорный, без фиксированной базовой суммы или фиксированного диапазона. AI предлагает `N` исходя из стратегических факторов и отдельно оценивает принятие/отказ.

Отпущенный и успешно выкупленный персонаж возвращается в **столицу своего Дома-владельца** и возвращается в режим `ДВОР` после очистки состояния плена.

При отказе пленник отправляется в ближайшую Крепость пленителя; если Крепостей нет — в столицу пленителя. Ближайшая Крепость определяется по минимальному числу рёбер канонической карты: land edge = 1, direct sea edge = 1; контроль территорий/портов и наличие армий не учитываются. При равной близости выбирает пленитель.

Событие **«Съезд заложников»** — утверждённое специальное исключение: в его раунд выкуп фиксирован на 2 золота.

## Data policy

Числовое значение, условие или ID, отличающиеся между Rules, Cards, MGD и Arena, считаются ошибкой либо явно зарегистрированным unresolved conflict.

Старые бинарные V5.7.1 артефакты учитываются только как historical baseline по SHA-256 из `RELEASE_MANIFEST.md`.
