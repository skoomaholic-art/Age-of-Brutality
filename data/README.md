# Game Data — V5.7.2-DEV

GitHub `main` репозитория `skoomaholic-art/Age-of-Brutality` является единственным source of truth проекта.

Текущая data-структура модульная. Граф источников и их приоритет зафиксирован в `canonical_manifest_v5.7.2.json`.

## Канонические источники

- `master_game_data_v5.7.2-dev.json` — DEV snapshot основных таблиц.
- `prisoners_v5.7.2-dev.json` — канонический модуль плена и выкупа.
- `intrigues_v5.7.2.json` — канонический модуль 40 Интриг, созданный 2026-09-12 как новый дизайн вместо утраченного исторического source.
- `canonical_manifest_v5.7.2.json` — машинно-читаемый граф приоритетов.

Приоритет: явно подтверждённое решение → canonical module → активные Rules/Data → historical baseline. Канонический модуль имеет приоритет над конфликтующим унаследованным полем монолитного MGD.

## Интриги

`data/intrigues_v5.7.2.json` фиксирует всю колоду: 40 уникальных `CARD_ID`, по 1 физической копии, цену, сложность, эффект и штраф доказанного Следа. AI не может генерировать или менять эти параметры.

Полный карточный набор определяется `cards/canonical_card_set_v5.7.2.json`: 151 уникальный дизайн / 160 физических карт с учётом двух копий каждого из 9 Советников.

Проверка карточных данных:

`node tools/generate_card_registry_v5_7_2.js --check`

## Плен

После захвата доступны: отпустить, удержать, потребовать выкуп N, казнить. Выкуп между людьми переговорный; событие «Съезд заложников» фиксирует N=2 только на свой раунд. Отпущенный/выкупленный персонаж возвращается в столицу своего Дома.

## Data policy

Любое числовое значение, условие или ID, отличающиеся между Rules, canonical modules, Cards, Arena и AI, считаются ошибкой либо явно зарегистрированным unresolved conflict.

Старые бинарные V5.7.1/RC артефакты используются только как historical baseline и не имеют приоритета над current source.
