# Game Data — V5.7.2-DEV

GitHub `main` является единственным source of truth проекта.

Текущая data-структура находится в процессе миграции от монолитного snapshot к модульным каноническим данным.

## Канонические источники

- `master_game_data_v5.7.2-dev.json` — импортированный DEV snapshot основных таблиц.
- `prisoners_v5.7.2-dev.json` — **канонический модуль механики плена и выкупа**; его значения имеют приоритет над унаследованными prisoner/ransom-полями baseline snapshot до следующей полной регенерации Master Game Data.

## Подтверждённое правило плена

После захвата доступны:

1. Отпустить пленника.
2. Взять в плен.
3. Требовать выкуп N.
4. Казнить.

Выкуп между людьми — переговорный, без фиксированной базовой суммы. AI предлагает `N` исходя из стратегических факторов и отдельно решает принимать ли встречное требование. При отказе пленник отправляется в ближайшую Крепость пленителя; если Крепостей нет — в столицу; при равной близости выбирает пленитель.

## Data policy

Числовое значение, отличающееся между Rules, Cards, MGD и Arena, считается ошибкой до явного решения проекта.

Старые бинарные V5.7.1 артефакты учитываются только как baseline по SHA-256 из `RELEASE_MANIFEST.md`; они не являются каноническим редактируемым source V5.7.2-DEV.

## Требует проверки

- AI scoring weights для выкупа;
- алгоритм определения ближайшей Крепости;
- событие `П-06 «Съезд заложников»`, где унаследованный текст фиксирует выкуп в 2 золота на раунд;
- место возвращения добровольно отпущенного пленника.
