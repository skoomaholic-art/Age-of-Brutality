# Game Data — V5.7.2-DEV

GitHub `main` является единственным source of truth проекта.

Текущая data-структура находится в процессе миграции от монолитного snapshot к модульным каноническим данным.

## Канонические источники

- `master_game_data_v5.7.2-dev.json` — импортированный DEV snapshot основных таблиц; требует регенерации после последних решений по плену.
- `prisoners_v5.7.2-dev.json` — **канонический модуль механики плена и выкупа**; имеет приоритет над унаследованными prisoner/ransom-полями монолитного snapshot.

## Подтверждённое правило плена

После захвата доступны:

1. Отпустить пленника.
2. Взять в плен.
3. Требовать выкуп N.
4. Казнить.

Выкуп между людьми — переговорный, без фиксированной базовой суммы. AI предлагает `N` исходя из стратегических факторов и отдельно решает принимать ли предложение.

Отпущенный и успешно выкупленный персонаж возвращается в **столицу своего Дома-владельца** и, не будучи назначенным командиром, возвращается в режим `ДВОР` по общей модели персонажей.

При отказе пленник отправляется в ближайшую Крепость пленителя; если Крепостей нет — в столицу пленителя. Ближайшая Крепость определяется по минимальному числу рёбер канонической карты: land edge = 1, direct sea edge = 1; контроль территорий/портов и наличие армий не учитываются. При равной близости выбирает пленитель.

Событие **«Съезд заложников»** — утверждённое специальное исключение: в его раунд выкуп фиксирован на 2 золота.

## Data policy

Числовое значение, отличающееся между Rules, Cards, MGD и Arena, считается ошибкой до явного решения проекта.

Старые бинарные V5.7.1 артефакты учитываются только как historical baseline по SHA-256 из `RELEASE_MANIFEST.md`.

## Открытые data-задачи

- полностью регенерировать монолитный MGD из актуальных канонических модулей;
- синхронизировать canonical CARD_ID события «Съезд заложников»: текущий монолитный MGD использует `EV-P06` для «Холодной войны»;
- продолжать баланс-тест AI scoring weights выкупа как implementation-параметров.
