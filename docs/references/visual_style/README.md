# Visual Style References

В этой папке зафиксированы 18 визуальных референсов художественного направления «Жестокого Века».

Открыть галерею: `index.html`.

Референсы используются для оформления карты, карточек, правил, памяток, жетонов и других физических/цифровых компонентов. Они **не заменяют** правила, Master Game Data, карточные данные, Arena или другие нормативные источники проекта.
