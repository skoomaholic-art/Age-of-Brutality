# Playtests

Новые тесты V5.7.1-STABLE должны логироваться отдельно от исторического baseline V5.7.0.

Минимально проверять: завершение партии, темп ОП, Влияние, дипломатию, войну, право прохода, плен/казнь/освобождение, династию, членов семьи и короля в армии, амбиции, экономику, крепости, AI decision-making, UI Arena, мёртвые механики, эксплойты и бесконечные циклы.
