# Playtests — V5.7.2

Актуальная цифровая линия плейтеста: **Arena V5.7.2-PLAYABLE-RC2**.

Исторические V5.7.0/V5.7.1 отчёты сохраняются только как baseline и не подменяют regression текущего билда.

## Что обязательно проверять

- может ли партия завершиться ровно после 6-го раунда;
- темп набора ОП по путям Война / Власть / Династия / Центр;
- темп и расходы Влияния;
- дипломатию: Пакт, Династический союз, Право прохода, разрыв отношений, передачу золота;
- войну, отступление, крепости, захват/удержание столиц и морские маршруты;
- плен, выкуп, отказ, освобождение, казнь и инварианты `ПЛЕН`/`Мёртв`;
- использование правителя и членов семьи как командиров;
- рождение, взросление, наследование, бастардов и регентство;
- амбиции и скрытую информацию;
- экономику;
- AI legal actions, scoring, target selection и объяснимость prisoner decisions;
- UI Arena;
- мёртвые механики, эксплойты, бесконечные циклы и state corruption.

## Обязательный сырой пакет ручного плейтеста

Для каждого ручного теста сохранять вместе:

- `Journal*.json`;
- `Diplomacy*.json`;
- `Houses*.json`;
- версию Arena/build SHA;
- seed, если он есть;
- краткое описание режима: Human/AI и состав Домов.

Сырые файлы нельзя заменять только итоговым текстовым отчётом: аудит должен иметь возможность пройти цепочку **Rules → Data → Arena → AI → фактический Playtest**.

## Текущий repo-status

Последний автоматизированный regression: `qa/reports/Game_Master_Report_V5.7.2_RC2_500seeds.md` — 500/500 партий завершены, 0 engine errors, 0 invalid actions, 0 prisoner-state invariant errors.

При этом `playtest/` пока **не содержит полный актуальный комплект ручных Journal/Diplomacy/Houses JSON**. Это source-migration debt и не должно трактоваться как отсутствие проблем в реальной Human-партии.
