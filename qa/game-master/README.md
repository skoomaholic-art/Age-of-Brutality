# Game Master / Rule Auditor

`game_master_runner.js` — воспроизводимый аудит Arena без браузера. Он извлекает встроенные `ARENA_DATA` и `ArenaEngine`, запускает серию детерминированных seeds и проверяет структурное завершение, ошибки/invalid actions, покрытие механик, судьбу командиров, отношения, win rate и статические рассинхронизации Rules ↔ Arena.

## Запуск

```bash
node qa/game-master/game_master_runner.js path/to/Arena.html 100 57001 > qa/game-master/results.json
```

По умолчанию: 100 партий, первый seed 57001.

## Подтверждённый тест плена

Game Master считает эталонным последнее подтверждённое решение проекта:

- Отпустить пленника;
- Взять в плен;
- Требовать выкуп N;
- Казнить.

Если Arena не хранит захвативший Дом, не показывает полный выбор, не исполняет/логирует эти ветки или смешивает смерть с ПЛЕН, это ошибка реализации.

Для Human↔Human **фиксированного диапазона N нет по правилу**: пленитель предлагает сумму, владелец принимает или отклоняет. Game Master не должен придумывать нижний/верхний предел переговоров. AI scoring weights являются implementation-параметрами и проверяются отдельно от правил людей.

## Ограничения текущего QA

Последний 500-seed RC2 report подтверждает структурную играбельность и покрытие, но не заменяет сверку с отсутствующими Cards/Map master sources и raw manual `Journal/Diplomacy/Houses`.

Текущие открытые discrepancies, которые будущий QA должен отслеживать отдельно: direct `hold` detention rule и дополнительный `-1 Влияние` за казнь при «Съезде заложников» в RC2. Оба пункта перечислены в `docs/KNOWN_ISSUES.md` и не должны молча превращаться в правила.
