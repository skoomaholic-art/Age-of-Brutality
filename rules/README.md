Приоритет источников:

**последнее явно подтверждённое решение → canonical module → активные V5.7.2 Rules/Data → historical baseline**.

Для любых спорных механик порядок проверки проекта:

**RULES → DATA → CARDS/MAP → ARENA → AI → ФАКТИЧЕСКИЙ ПЛЕЙТЕСТ**.
