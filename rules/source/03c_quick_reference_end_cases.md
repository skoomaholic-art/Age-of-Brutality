# 35. Конец игры

После фазы Династии R6 новые раунды не начинаются. Проверьте все
достижения «Конец игры», Амбицию и контроль. Сложите ОП всех путей.
Побеждает максимум ОП; тай-брейки: Влияние → территории → золото →
совместная победа.

# 36. Обязательные редкие случаи

- Если два эффекта одновременно убивают/перемещают персонажа, сначала
  полностью разрешается более ранний по порядку приоритета; последующий
  эффект, потерявший законную цель, не применяется.

- Если захваченная Крепость позже уничтожена картой, её жетон удаляется
  из игры и не возвращается прежнему владельцу.

- Если брак прекращается смертью супруга, незаработанная награда за
  полный раунд не выдаётся.

- Если защитникам некуда отступить или превышен лимит 8, лишние основные
  воины удаляются после применения потерь.

- Подкрепление всегда связано с конкретным физическим воином; оно не
  может быть одновременно основным участником боя.

- Вход в пустую вражескую территорию всё равно требует законного
  действия, законной армии в точке отправления, полного маршрута и
  отсутствия запрещающего Пакта/союза. После успешной валидации такого
  входа бросок боя не выполняется: территория автоматически занимается
  выжившей атакующей армией и не считается бросковым PvP-боям для
  статистики. Прямо менять владельца территории без этой процедуры
  запрещено. Если цель — чужая столица, процедура VP-W3A/W3B применяется
  как обычно.
