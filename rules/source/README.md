## Последние синхронизированные решения

- Плен: победитель выбирает `Отпустить пленника` / `Взять в плен` / `Требовать выкуп N` / `Казнить`.
- Human ↔ Human: фиксированной таблицы и фиксированного диапазона выкупа нет; пленитель предлагает `N`, вторая сторона принимает или отклоняет.
- AI: сумма и решение определяются стратегическим scoring по потребностям, амбиции/целям, ценности пленника, положению Дома пленника и общему положению сторон; случайный фиксированный выкуп запрещён.
- Освобождённый или успешно выкупленный персонаж возвращается в **столицу своего Дома-владельца**, очищает `heldBy`/статус плена и возвращается в режим `ДВОР`.
- При отказе от выкупа пленник отправляется в ближайшую Крепость пленителя; если Крепостей нет — в столицу пленителя; при равной близости нескольких Крепостей выбирает пленитель.
- Ближайшая Крепость определяется по минимальному числу рёбер канонической карты: land edge = 1, direct sea edge = 1; контроль территорий/портов и наличие армий не учитываются.
- Событие `Съезд заложников` — специальное исключение: в его раунд выкуп фиксирован на **2 золота**.
- Старое общее правило фиксированного выкупа 3 золота больше не канонично.
- `Айрель` — каноническое написание идентификатора Дома.
- Развод: 1 действие +3 Влияния по существующим Data/Arena; полная процедура находится в DEV rule source.
- Начальная рука Интриг: 0 карт. Добор впервые выполняется действием «Добор Интриги» по новому каноническому модулю.
