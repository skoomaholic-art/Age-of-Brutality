# Жестокий Век — Visual Print & Play

Текущая рабочая линия визуала: **V5.7.2-VISUAL-RC1 + HTML Visual Editor V2.1**. Она синхронизируется с Arena **V5.7.2-PLAYABLE-RC2**.

Это в первую очередь **физическая настольная игра**. Arena остаётся вспомогательным инструментом для плейтестов и QA.

## Visual source

- `docs/` — style guide, print guide, physical-playability audit и QA;
- `templates/` — editable SVG-шаблоны карточек;
- `arena/` — tabletop skin для Arena;
- `map/` — styled map source без изменения канонической topology;
- `build/` — генератор печатного visual pack;
- `html_v2/` — исходная слоистая архитектура;
- `html_v21/` — исправленная самодостаточная HTML-архитектура после ручного теста.

## HTML Visual Editor V2.1

Фоновые изображения не содержат игрового текста. Названия, ID, числа, характеристики и правила выводятся HTML-слоем.

Standalone HTML обязан работать без внешних ассетов: фон и рабочая копия SVG-иконок встраиваются внутрь файла. Отдельные SVG остаются самостоятельными печатными/редакторскими ассетами.

У каждой карточки есть явное HTML-меню редактирования и загрузка собственного изображения с режимами `cover` / `contain` и настройкой позиции. Карта имеет отдельный редактор подписей территорий и Домов; X/Y двигает только HTML-метки, но не меняет topology.

Карта поддерживает печать целиком и сегментами **4×3 = 12 листов A4**. Карточки поддерживают печать всего пака и одной выбранной карты. Динамические состояния персонажей отслеживаются внешними жетонами.

Visual/print линия остаётся RC и не является STABLE до полной синхронизации Rules ↔ Data ↔ Cards ↔ Map ↔ Arena ↔ Print.
