# Component Usage Guide — V5.7.2-VISUAL-RC1

## Статичная карточка
На карточке остаются только постоянные данные: имя, Дом/категория, характеристики, постоянное правило, условия и эффект.

## Динамические состояния
ДВОР / АРМИЯ / ПЛЕН, здоровье, брак, командование, регентство, бдительность и использование способности отмечаются внешними жетонами. Карточка персонажа не должна «переключаться» как цифровой UI.

## Дипломатия
Пакт, Право прохода и Династический союз отмечаются отдельными дипломатическими маркерами между зонами Домов. Постоянного WAR-жетона нет, потому что постоянного состояния «война» в текущих правилах нет.

## Изображения
В SVG-шаблонах изображение заменяется внутри группы `ART_SLOT`. Игровые текстовые поля находятся в `TEXT_FIELDS`.
