# Print Guide — V5.7.2-VISUAL-RC1

- A4, 9 карт на лист.
- Физический trim карточки: 63×88 мм.
- Bleed: 3 мм со всех сторон.
- Печатать карточки в масштабе 100%, без `Fit to page`.
- Каждая карта существует отдельно как PNG 300 dpi и отдельный PDF 69×94 мм.
- Для каждой категории есть `*_Full_Pack_Print.pdf` и `*_Backs_Print.pdf`.
- Общий пак: `Жестокий_Век_Все_Карточки_Full_Pack_Print.pdf`.
- Рубашки зеркалируются по строкам для типичной двусторонней печати; перед тиражом обязательно напечатать один тестовый лист.
- Карта: full-size 840×560 мм + A4 tiled-версия с overlap.
- SVG-шаблоны предназначены для самостоятельной замены изображения без перестройки карты.
