# Visual Style Guide — V5.7.2-VISUAL-RC1

## Принцип
Физическая настольная игра важнее цифрового оформления. Порядок приоритетов: **функциональность → читаемость → визуальная иерархия → атмосфера → декоративность**.

## Направление
«Страдающее средневековье» без превращения игры в мем: пергамент, иллюминированная рукопись, геральдика, маргиналии, слегка гротескная средневековая наивность.

## Карточки
- trim: 63×88 мм;
- bleed: 3 мм;
- 300 dpi;
- `ART_SLOT` — отдельная область для заменяемого изображения;
- динамические состояния отслеживаются внешними жетонами, а не цифровой подменой лица карты;
- карта должна оставаться понятной в распечатанном виде без Arena.

## Цвета Домов
- ⚔ **Варкайр** — `#7c8792`;
- ♜ **Сайрвен** — `#718c3f`;
- ✦ **Ортайн** — `#a9762f`;
- ◆ **Эркай** — `#765584`;
- ☾ **Тасвар** — `#9f4139`;
- ❖ **Айрель** — `#3f7776`.

Цвет всегда дублируется названием/символом, чтобы компонент не зависел только от цветового восприятия.

## Карта
Визуальная доработка не имеет права менять территории, границы, порты, морские маршруты, столицы и canonical topology. Visual RC1 добавляет только неигровой декоративный слой и типографическую унификацию.
