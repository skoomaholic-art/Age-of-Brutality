# Жестокий Век — HTML Visual System V2

Зафиксирован новый принцип визуального слоя физической настольной игры:

- фон карты/карточек не содержит игрового текста;
- все названия, ID, числовые значения и правила выводятся HTML-слоем;
- игровые и служебные иконки хранятся отдельными SVG-ассетами;
- пользователь может менять текст и загружать изображения без перерисовки фона;
- карта сохраняет каноническую topology;
- карта поддерживает печать целиком и сегментами 4×3 на 12 листов A4;
- карточки поддерживают печать полного пака и выбранной карточки;
- динамические состояния персонажей остаются внешними жетонами и не запекаются в печатную карту.

Локальный review-build: `Жестокий_Век_HTML_Visual_System_V2.zip`.

Статус: visual source / print prototype, не STABLE.
