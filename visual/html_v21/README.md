# HTML Visual Editor V2.1

Исправление по ручному тесту HTML Visual V2.

## Что исправлено

- standalone HTML больше не зависит от внешних `assets/...`: фон карты, фон карточек и рабочие SVG-иконки встраиваются внутрь HTML;
- у каждой карточки есть явная правая панель HTML-редактора;
- редактор карточки меняет: название, подзаголовок, ID, цвет, правила и все характеристики;
- у каждой карточки есть отдельная загрузка изображения;
- для изображения доступны `cover` / `contain`, позиция X/Y и удаление;
- двойной клик по арт-слоту открывает выбор изображения;
- карта имеет отдельную панель редактирования HTML-подписей территорий и Домов;
- изменение X/Y на карте двигает только HTML-метку, но не меняет каноническую topology;
- карта печатается 4×3 = 12 сегментов A4;
- жетоны используют встроенные SVG-иконки и редактируемые HTML-подписи;
- карточки и карта поддерживают сохранение в localStorage и экспорт/импорт JSON.

## Принцип

`STATIC ART BACKGROUND -> INLINE/SEPARATE SVG ICONS -> HTML TEXT/DATA -> PRINT`

Игровой текст не должен быть запечён в фоновые изображения.

Карточка остаётся статичной для физической печати; динамические состояния отмечаются внешними жетонами.

Версия: `V5.7.2-HTML-VISUAL-V2.1`.
