# Map Visual Source — V5.7.2

## Active digital technical layout

The active Arena layout is the inline canonical topology SVG generated by `topologyMap()` in `arena/source/current/ui_runtime.js`.

It renders all 52 live territory states, W1/W2/W3 on the west, E1/E2/E3 on the east, S01–S05 in the central sea, all 81 land edges and all 23 sea routes. Eastern mainland ports remain `E1-1`, `E2-1`, `E3-1`.

The machine-readable authority for adjacency, ports and sea routes remains `map/canonical_topology_v5.7.2.json`. The Arena schematic is generated from that data, so it cannot silently invent a route.
